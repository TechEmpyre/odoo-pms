Frequently Asked Questions

What is the purpose of user restrictions for projects and tasks?
User restrictions help ensure that only authorized users can view or modify specific projects and tasks, enhancing security and confidentiality within the organization.
What are the criteria for accessing a project or task?
Access is usually granted based on the following criteria: User membership in a specific group (e.g., "View Limited Projects and Tasks"). Users explicitly assigned to the project or task via the access fields (e.g., project_access_user_ids).
